# Spectral-Spatial Patch Processing in Hyperspectral Images

## Project Overview

This project focuses on hyperspectral image classification using deep learning techniques for extracting and combining spectral and spatial features.

The proposed approach uses spectral band selection, spatial patch processing, Convolutional Neural Networks (CNN), and Transformer-based architectures for hyperspectral image classification.

## Key Features

* Hyperspectral image preprocessing
* Informative spectral band selection
* Spatial patch extraction
* CNN-based spatial feature extraction
* Vision Transformer-based contextual feature extraction
* Feature fusion for classification
* Data augmentation and normalization
* Indian Pines dataset
* Performance evaluation using classification metrics

## Technologies

* Python
* Deep Learning
* Convolutional Neural Network (CNN)
* Vision Transformer (ViT)
* Hyperspectral Image Processing
* Indian Pines Dataset

## Reported Results

The CNN–Vision Transformer approach reported a validation accuracy of **98.11%** on the Indian Pines dataset.
